# npm 组件许可索引

本表覆盖 package-lock 中 409 个非根条目，包括嵌套版本和多平台可选包。源码候选不包含 node_modules 或这些包的可执行二进制。这里保留本机可取得的包内原许可、声明和版权；未安装的平台包通过锁中的版本、来源归档和 integrity 定位，准备对应安装资源时仍须核对实物原声明。

busboy 和 streamsearch 的锁元数据没有 license 字段，但包内 LICENSE 为 MIT。部分包将声明放在 README 而非独立 LICENSE；对应许可章节原样摘录。esbuild、Canvas、rolldown 的本机 native 包及 humanfs types 的共同项目声明来自对应本机项目包，不据此声称其所有二进制内组件已完成核对。

本表的 SPDX 标签是索引，不能替代原许可；包内多重许可、附带声明和版权仍须完整保留。许可证中的第三方作者邮箱属于原版权声明，不能按 SC 私人信息误删。
