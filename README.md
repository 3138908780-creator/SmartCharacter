# SmartCharacter 本地字幕包装工具

SmartCharacter 在本机浏览器中读取视频和 SRT，提供字幕编辑、重点词包装、六款卡片、动画演示和透明字幕视频导出。AI 可选，只分析原始字幕重点及语义结构，效果匹配在本机完成。

本目录来自已验收产品提交 d1f3073，当前统一交付版本为 20261010，包含 Windows 导出 UTF-8 修复。字体、渲染资源和旧工程兼容功能保留。个人素材、记录、密钥、依赖目录和原开发仓库历史不随交付。

## 安装与使用

普通用户在项目发布后，从 GitHub 仓库的 **Releases** 页面下载对应电脑的完整安装 ZIP：

| 电脑 | 完整安装包 |
| --- | --- |
| Apple Silicon Mac（M 系列芯片） | `SC-Mac-AppleSilicon-20261010.zip` |
| Intel Mac | `SC-Mac-Intel-20261010.zip` |
| Windows x64 | `SC-Windows-20261010.zip` |

完整解压后，Mac 首次双击“安装 SmartCharacter.command”，Windows 首次双击“安装 SmartCharacter.cmd”；安装完成再双击同目录的“启动 SmartCharacter”。完整包可以离线安装，不要求电脑已有 Node 或 Python。Windows 不要直接在压缩包窗口中运行安装入口。

Mac 首轮验收范围为 macOS 14+；Windows 为 Windows 11 x64。工作台默认打开 `http://127.0.0.1:4318`，保持启动窗口运行。关闭窗口或按 Ctrl+C 停止服务。

GitHub 的 Code → Download ZIP、Git clone 和 `SC-public-source-20261010.zip` 用于维护和开发，不包含完整运行组件，不能仅凭安装脚本完成首次安装。普通用户请选择上表的完整包。源码维护者按 [本地启动说明](本地启动说明.md) 构建和装配。目前没有自动更新；实际下载入口以官方仓库发布后的 Releases 为准。

安装位置、安全打开、导出文件查找、离线修复和手动开发方式见 [本地启动说明](本地启动说明.md)，验收状态见 [三平台实机验收表](三平台实机验收表.md)，旧包更新步骤见 [更新记录](CHANGELOG.md)。导出的是透明 ProRes 4444 MOV 字幕层，可在剪辑软件中叠加到原视频上。
